# advent-of-code-2022
My solutions for Advent of Code 2022

## Python setup

Create and activate the virtual environment, then install the dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

In VS Code, open a Python file and use **Run and Debug** with the **Python: Current File** configuration to run or debug it. Puzzle inputs are read from `input/`.
